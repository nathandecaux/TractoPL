# Complete Workflow Example

[`run_workflow.sh`](run_workflow.sh) runs the maintained TractoPL workflow for
one BIDS participant. It stops as soon as one command fails.

```shell
bash examples/run_workflow.sh \
  /data/my-bids-dataset \
  /data/my-atlas/atlas.json \
  01
```

The arguments are:

| Argument | Meaning |
| --- | --- |
| `bids-root` | Root directory of the input BIDS dataset. Outputs are written below its `derivatives/` directory. |
| `atlas-manifest` | Atlas JSON manifest. Relative paths inside it are resolved relative to the manifest file. |
| `subject-id` | BIDS subject label without the `sub-` prefix, for example `01`. |

## Prerequisites

Install TractoPL and its runtime dependencies, then make the external tools
available through the `TRACTOPL_*` environment variables described in the root
[README](../README.md). The workflow requires Anima, MRtrix3, ANTs, and
TractoSearch.

The input dataset must contain at least:

```text
bids-root/
  sub-01/
    anat/
      sub-01_T1w.nii.gz
    dwi/
      sub-01_dwi.nii.gz
      sub-01_dwi.bval
      sub-01_dwi.bvec
    sourcedata/
      sub-01_dicoms/
        *.dcm
```

By default preprocessing also expects a reverse-phase B0 image selected by the
BIDS entity `desc-b0reversed`, for example:

```text
sub-01/dwi/sub-01_desc-b0reversed_dwi.nii.gz
```

For datasets without that acquisition, run preprocessing separately with
`tractopl-preprocessing --without-reversed-b0` before continuing with the
remaining commands.

The atlas manifest requires `name`, `reference`, and `bundles_dir`. The full
workflow additionally requires `centroids_dir` for tractometry. `bundles_dir`
must contain the reference bundle models named `summed_<bundle-name>.trk` or
`.vtk`; `centroids_dir` must contain the matching
`summed_<bundle-name>_centroids.vtk` files.

## Workflow Steps

### 1. DWI preprocessing

```shell
tractopl-preprocessing --subject 01 --db-root /data/my-bids-dataset
```

**Reads**

- Raw DWI, `.bval`, and `.bvec` files.
- A T1-weighted image.
- DICOM files from `sourcedata/sub-01_dicoms/`.
- A reversed B0 image unless `--without-reversed-b0` is used.

**Writes** `derivatives/preprocessing/sub-01/`

- Corrected DWI and b-vectors, identified as `desc-preproc`.
- Diffusion tensor image, identified with `model-DTI`.
- FA image, identified with `metric-FA`.
- Brain mask, identified as `label-brain`, `space-B0`, `suffix-mask`.

The corrected DWI, b-values, corrected b-vectors, and brain mask are required
by the MSMT-CSD and MCM estimation steps. The FA image is required for atlas
registration and MCM projection.

### 2. MSMT-CSD, fixels, and whole-brain tractography

```shell
tractopl-msmt-csd --subject 01 --db-root /data/my-bids-dataset \
  --step response --step fod --step fixels --step fixels2peaks \
  --step fixel_density --step ifod2_tracto --n-streamlines 1000000
```

**Reads**

- Preprocessed DWI and b-vectors from `derivatives/preprocessing/`.
- Raw b-values.
- Brain mask from preprocessing.

**Writes** `derivatives/msmt_csd/sub-01/`

- WM, GM, and CSF tissue response functions.
- WM, GM, and CSF FOD images.
- WM fixels and peaks derived from fixels.
- WM fixel/peak density image.
- Whole-brain iFOD2 tractogram, identified as `label-brain`, `algo-ifod2`, and
  `suffix-tracto`.

The density image is used by default to estimate the number of MCM anisotropic
compartments per voxel. The whole-brain tractogram is the input to bundle
segmentation.

### 3. MCM estimation

```shell
tractopl-mcm estimation --subject 01 --db-root /data/my-bids-dataset
```

**Reads**

- Preprocessed DWI, raw b-values, corrected b-vectors, and brain mask.
- Fixel density image from `derivatives/msmt_csd/` when peak matching is used.

**Writes** `derivatives/mcm_tensors/sub-01/`

- MCM archive (`.mcmx`) containing the fitted microstructure model.
- MCM-derived maps used for quality control and downstream projection.

The `.mcmx` file is required by the projection step.

### 4. Atlas registration and bundle segmentation

```shell
tractopl-bundle-seg segmentation --subject 01 --db-root /data/my-bids-dataset \
  --atlas /data/my-atlas/atlas.json
```

**Reads**

- Subject FA image from preprocessing.
- Whole-brain iFOD2 tractogram from MSMT-CSD.
- Atlas reference FA and bundle models from the manifest.

**Writes** `derivatives/bundle_seg/sub-01/`

- ANTs transforms and warped atlas reference image.
- Atlas bundle models transformed into subject space.
- Subject-specific segmented bundle tractograms generated by TractoSearch.
- Atlas centroids transformed into subject space when supplied by the atlas.

The segmented bundle tractograms are required for MCM projection. The
registered atlas bundles and centroids are required for the default tractometry
association.

### 5. MCM projection onto segmented bundles

```shell
tractopl-mcm projection --subject 01 --db-root /data/my-bids-dataset \
  --bundle-pipeline bundle_seg
```

**Reads**

- MCM archive from `derivatives/mcm_tensors/`.
- FA image from preprocessing.
- Segmented bundle tractograms from `derivatives/bundle_seg/`.

**Writes** `derivatives/mcm_tensors/sub-01/`

- One VTK tractogram per segmented bundle, enriched with MCM metrics.

These metric-bearing VTK files are the primary input for tractometry.

### 6. Tractometry association

```shell
tractopl-tractometry association --subject 01 --db-root /data/my-bids-dataset \
  --atlas /data/my-atlas/atlas.json --mcm-pipeline mcm_tensors \
  --bundle-pipeline bundle_seg
```

**Reads**

- MCM metric VTK bundle tractograms from `derivatives/mcm_tensors/`.
- Registered atlas bundles and centroids from `derivatives/bundle_seg/`.
- Subject FA image for reference geometry.

**Writes** `derivatives/tractometry/sub-01/`

- Association VTK files.
- Per-bundle metric CSV files, including statistics by centroid position.
- `.tag_tractometry` at the root of the selected tractometry derivative.

The dashboard uses the marker, BIDS derivative metadata, or metric CSV files to
automatically discover this derivative. Use a custom output location with
`tractopl-tractometry ... --pipeline <name>`; it will remain discoverable.

## Expected Derivative Layout

The exact BIDS filenames contain additional entities, but the resulting layout
has this shape:

```text
bids-root/
  derivatives/
    preprocessing/
      sub-01/
        dwi/          # corrected DWI, tensors, FA, b-vectors
        anat/         # brain mask
    msmt_csd/
      sub-01/
        tracto/       # whole-brain iFOD2 tractogram
        dwi/          # responses, FODs, fixels, peaks, density
    mcm_tensors/
      sub-01/
        dwi/          # .mcmx archive and MCM maps
        tracto/       # metric-bearing VTK bundle tractograms
    bundle_seg/
      sub-01/
        atlas/        # transformed atlas bundles and centroids
        tracto/       # TractoSearch segmented bundles
        xfm/          # ANTs transforms
    tractometry/
      .tag_tractometry
      sub-01/
        metric/       # per-bundle tractometry CSV files
        tracto/       # association VTK files
```

## Running Individual Steps

`run_workflow.sh` is deliberately a conservative example. Run each command
individually when you need to change its pipeline name, number of streamlines,
MCM model options, or tractometry settings. Each command provides its accepted
options through `--help`.

The Apptainer equivalents are
[`run_workflow_apptainer.sh`](run_workflow_apptainer.sh) and
[`run_workflow_apptainer_dev.sh`](run_workflow_apptainer_dev.sh). They invoke
this same workflow inside an image while binding the dataset and atlas paths.
